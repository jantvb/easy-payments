# Easy Payments

Angular checkout library with mock payments, real Stripe card (Payment Element), real PayPal (Buttons + Orders v2), real Google Pay TEST (official button + Stripe gateway), and real Klarna (Stripe Payment Element).

**Mock mode does not process real payments.** Stripe secret keys, PayPal Client Secrets, and Klarna API secrets never belong in Angular.

See the workspace [README](../../README.md) for quick start, Stripe TEST, PayPal Sandbox, Google Pay TEST, Klarna via Stripe, trusted pricing, and production notes.
