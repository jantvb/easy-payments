# Easy Payments

Angular checkout library with mock payments, real Stripe card (Payment Element), and real PayPal (official Buttons + Orders v2).

**Mock mode does not process real payments.** Stripe secret keys and PayPal Client Secrets never belong in Angular.

See the workspace [README](../../README.md) for quick start, Stripe TEST MODE, PayPal Sandbox, backend contract, trusted pricing, security notes, and third-party trademark guidance.
