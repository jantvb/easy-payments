# Easy Payments

Angular checkout library with mock payments, real Stripe card (Payment Element), real PayPal (Buttons + Orders v2), and real Google Pay TEST (official button + Stripe gateway).

**Mock mode does not process real payments.** Stripe secret keys and PayPal Client Secrets never belong in Angular.

See the workspace [README](../../README.md) for quick start, Stripe TEST, PayPal Sandbox, Google Pay TEST, trusted pricing, and production notes.
