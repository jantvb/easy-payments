1. In `README.md`, replace `**PAYPAL_SUPPORT_URL_REQUIRED**` with:

   `[Support via PayPal](YOUR_REAL_PAYPAL_SUPPORT_URL)`

2. Create `.github/FUNDING.yml`:

```yml

custom:
  - YOUR_REAL_PAYPAL_SUPPORT_URL
```
